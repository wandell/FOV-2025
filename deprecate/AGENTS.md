# Instructions for AI Agents

Before doing any work in this repository, read [`.github/copilot-instructions.md`](.github/copilot-instructions.md) first. It is the canonical entry point: project context, repository layout, non-negotiables, and an index of the topic-specific skills in [`.github/skills/`](.github/skills/) (formatting/mechanics/editorial conventions plus per-domain scientific conventions for optics, retina, visual cortex, color, pattern vision, and motion/depth), each following the [Agent Skills](https://agentskills.io) `SKILL.md` format.

Consult the relevant `SKILL.md` file(s) before editing chapter content.
